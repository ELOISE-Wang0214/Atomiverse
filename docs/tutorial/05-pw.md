# Tutorial 5: Plane-Wave DFT for Periodic Systems

This tutorial assumes you have read
[Tutorial 1: Toy SCF from First Principles](01-scf.md) and
[Tutorial 4: Unrestricted Kohn-Sham DFT](04-uks.md).

The first four tutorials covered **molecular** electronic structure with
atom-centered Gaussian basis sets. This tutorial moves to **periodic** systems —
crystals, surfaces, and bulk materials — where the natural basis is **plane
waves**.

The guiding question is:

> how does the SCF iteration change when we replace Gaussian basis functions
> with plane waves, and what new physics does that unlock?

We use a single concrete example throughout: **silicon in the diamond structure**,
described by a norm-conserving pseudopotential under the local-density
approximation (LDA). Silicon is the smallest nontrivial periodic system that
still teaches the full method.

## Why Plane Waves?

For a molecule in a large box, localised Gaussian orbitals are efficient: you
need only a handful per atom. For a periodic crystal, the wavefunction extends
over the entire lattice. A plane-wave expansion

\[
\psi_{n\mathbf{k}}(\mathbf{r}) =
\sum_{\mathbf{G}} c_{n\mathbf{k}}(\mathbf{G}) \,
e^{i(\mathbf{k}+\mathbf{G})\cdot\mathbf{r}}
\]

is the natural choice because:

1. **Bloch's theorem** is satisfied automatically — each **k**-point labels an
   irreducible representation of the translation group.
2. **Systematic convergence** — increasing the kinetic-energy cutoff
   \f$E_{\mathrm{cut}}\f$ adds more plane waves and converges the basis to
   completeness. There is no basis-set superposition error.
3. **FFT acceleration** — switching between reciprocal space (where the
   kinetic energy and Hartree potential are diagonal) and real space (where
   the exchange-correlation potential is local) costs only
   \f$\mathcal{O}(N \log N)\f$.
4. **Forces and stress** are simple — no Pulay forces from basis-set
   derivatives.

The price is that plane waves are inefficient for core electrons: the
\f$1s\f$ orbital of silicon oscillates on the scale of 0.1 Å, requiring an
enormous \f$E_{\mathrm{cut}}\f$. That is why we introduce pseudopotentials.

## Pseudopotentials: Freezing the Core

A **norm-conserving pseudopotential** replaces the bare nuclear Coulomb
potential with a softer effective potential that:

- matches the all-electron potential outside a core radius \f$r_c\f$,
- produces pseudized valence wavefunctions that are nodeless inside \f$r_c\f$,
- preserves the norm of each valence wavefunction inside \f$r_c\f$,
- reproduces the same scattering properties (logarithmic derivatives) as the
  all-electron atom.

In Atomiverse, pseudopotentials are read from **UPF v1** (Unified
Pseudopotential Format) XML files. The reader is declared in
[`include/atomiverse/cpu/pw/internal/upf_reader.h`](../../include/atomiverse/cpu/pw/internal/upf_reader.h).

A UPF file provides:

| Quantity | Symbol | Role |
|----------|--------|------|
| Valence charge | \f$Z_{\mathrm{val}}\f$ | Number of valence electrons per atom |
| Local potential | \f$V_{\mathrm{loc}}(G)\f$ | Fourier-space local part of the pseudopotential |
| \f$\ell_{\max}\f$ | — | Maximum angular momentum channel |
| KB projectors | \f$\beta_\ell\f$ | Kleinman-Bylander non-local projectors |
| Atomic density | \f$\rho_{\mathrm{atom}}(r)\f$ | Reference density for non-linear core correction |

For silicon, \f$Z_{\mathrm{val}} = 4\f$ and the SG15 ONCV pseudopotential
(Hamann, PRB 88, 085117, 2013) gives accurate results at moderate cutoffs.

## G-Vectors and the Energy Cutoff

In a periodic cell defined by lattice vectors \f$\mathbf{a}_1, \mathbf{a}_2,
\mathbf{a}_3\f$, the reciprocal lattice vectors are

\[
\mathbf{G} = n_1 \mathbf{b}_1 + n_2 \mathbf{b}_2 + n_3 \mathbf{b}_3,
\qquad
\mathbf{b}_i \cdot \mathbf{a}_j = 2\pi \delta_{ij}.
\]

The plane-wave basis is truncated by keeping only those \f$\mathbf{G}\f$ that
satisfy

\[
\frac{1}{2} |\mathbf{k} + \mathbf{G}|^2 \le E_{\mathrm{cut}}.
\]

The G-vector enumeration is done by `enumerate_g_vectors()` in
[`include/atomiverse/cpu/pw/internal/g_vector.h`](../../include/atomiverse/cpu/pw/internal/g_vector.h).
The number of plane waves scales roughly as \f$N_G \propto
E_{\mathrm{cut}}^{3/2} \Omega\f$, where \f$\Omega\f$ is the cell volume.

A typical cutoff for silicon is \f$E_{\mathrm{cut}} = 30\f$ Ry, which yields of
order \f$10^3\f$ plane waves for a 2-atom cell.

## k-Point Sampling

For an infinite crystal, physical quantities must be integrated over the
Brillouin zone. In practice, this integral is approximated by a weighted sum
over a discrete **Monkhorst-Pack mesh**:

\[
\frac{1}{\Omega_{\mathrm{BZ}}} \int_{\mathrm{BZ}} f(\mathbf{k}) \, d\mathbf{k}
\;\approx\;
\sum_i w_i \, f(\mathbf{k}_i).
\]

Atomiverse implements this in
[`include/atomiverse/cpu/pw/internal/kpoint.h`](../../include/atomiverse/cpu/pw/internal/kpoint.h)
as `generate_mp_mesh(nx, ny, nz)`, returning a `KPointGrid` with uniform
weights summing to 1.

For silicon, a \f$4\times4\times4\f$ mesh (64 k-points) is a reasonable
starting point.

## The PW SCF Cycle

The phase sequence is the same as in Tutorial 1, but the components are
completely different:

\[
\texttt{build\_hamiltonian}
\rightarrow
\texttt{diagonalize}
\rightarrow
\texttt{build\_density}
\rightarrow
\texttt{convergence\_check}
\rightarrow
\texttt{end\_of\_step}.
\]

Here is what each phase does in a plane-wave context.

### Phase 1: `build_hamiltonian`

Four components execute in order:

**PW_Poisson** (order –100): Solve the Hartree potential in reciprocal space:

\[
V_{\mathrm{H}}(\mathbf{G}) = \frac{4\pi}{G^2} \, \rho(\mathbf{G}),
\qquad \mathbf{G} \neq \mathbf{0}.
\]

The \f$\mathbf{G}=0\f$ component is set to zero (it cancels with the uniform
neutralizing background). Implemented in
[`include/atomiverse/cpu/pw/pw_poisson.h`](../../include/atomiverse/cpu/pw/pw_poisson.h).

**PW_LDA** (order –50): Evaluate the exchange-correlation potential on the
real-space grid via FFT:

\[
\rho(\mathbf{r}) = \mathrm{FFT}^{-1}[\rho(\mathbf{G})],
\qquad
V_{\mathrm{xc}}(\mathbf{r}) = \left.\frac{\delta
E_{\mathrm{xc}}[\rho]}{\delta \rho}\right|_{\rho(\mathbf{r})},
\qquad
V_{\mathrm{xc}}(\mathbf{G}) = \mathrm{FFT}[V_{\mathrm{xc}}(\mathbf{r})].
\]

The XC functional is the same Slater exchange + VWN5 correlation used in
Tutorial 4, evaluated by `cpu::scf::evaluate_xc` at each grid point.
Implemented in
[`include/atomiverse/cpu/pw/pw_lda.h`](../../include/atomiverse/cpu/pw/pw_lda.h).

**PW_Hamiltonian** (order 0): Precompute the kinetic energy diagonal:

\[
T(\mathbf{G}) = \frac{1}{2} |\mathbf{k} + \mathbf{G}|^2.
\]

This is constant across SCF iterations because the G-vectors and k-points are
fixed. Implemented in
[`include/atomiverse/cpu/pw/pw_hamiltonian.h`](../../include/atomiverse/cpu/pw/pw_hamiltonian.h).

**PW_Veff** (order +50): Assemble the effective potential:

\[
V_{\mathrm{eff}}(\mathbf{G}) =
V_{\mathrm{loc}}(\mathbf{G}) +
V_{\mathrm{H}}(\mathbf{G}) +
V_{\mathrm{xc}}(\mathbf{G}).
\]

Implemented in
[`include/atomiverse/cpu/pw/pw_veff.h`](../../include/atomiverse/cpu/pw/pw_veff.h).

### Phase 2: `diagonalize` — Davidson Iteration

In the molecular tutorials, diagonalizing a \f$2\times2\f$ or \f$7\times7\f$
matrix was trivial. Plane-wave Hamiltonians are \f$N_G \times N_G\f$ with
\f$N_G \sim 10^3\f$–\f$10^6\f$, and we only need the lowest few eigenpairs.

The **Davidson method** is a matrix-free iterative diagonalizer that builds a
small subspace and refines it until the desired eigenpairs converge. The
key operation is the Hamiltonian application

\[
H \psi = \left(T + V_{\mathrm{eff}}\right) \psi,
\]

which uses FFTs to apply \f$V_{\mathrm{eff}}\f$ in real space without ever
forming the full \f$N_G \times N_G\f$ matrix.

Atomiverse's Davidson solver is in
[`include/atomiverse/cpu/pw/pw_davidson.h`](../../include/atomiverse/cpu/pw/pw_davidson.h).

### Phase 3: `build_density` — Density Construction and Mixing

From the occupied eigenstates, the output density is

\[
\rho_{\mathrm{out}}(\mathbf{G}) =
\sum_{n}^{\mathrm{occ}} \sum_{\mathbf{G}'}
c_n^*(\mathbf{G}') \, c_n(\mathbf{G}' + \mathbf{G}).
\]

Direct substitution of \f$\rho_{\mathrm{out}}\f$ as the next input density
often diverges. The **Pulay mixing** (DIIS in density space) stabilizes
convergence by extrapolating from the history of input and output densities:

\[
\rho_{\mathrm{in}}^{(k+1)} =
\rho_{\mathrm{in}}^{(k)} + \beta \Delta\rho^{(k)} +
\sum_{i} \alpha_i \left(\rho_{\mathrm{in}}^{(i+1)} -
\rho_{\mathrm{in}}^{(i)}\right).
\]

When the Pulay history is too small, it falls back to simple linear mixing
with \f$\beta \approx 0.4\f$. Implemented in
[`include/atomiverse/cpu/pw/pw_density.h`](../../include/atomiverse/cpu/pw/pw_density.h).

### Phase 4: `convergence_check`

Convergence is measured by the RMS change in density:

\[
\Delta\rho =
\sqrt{\frac{1}{N_G} \sum_{\mathbf{G}}
|\rho_{\mathrm{out}}(\mathbf{G}) -
\rho_{\mathrm{in}}(\mathbf{G})|^2 }.
\]

A warmup period (default 2 iterations) suppresses false convergence from the
initial guess. Implemented in
[`include/atomiverse/cpu/pw/pw_convergence.h`](../../include/atomiverse/cpu/pw/pw_convergence.h).

## Ewald Summation: The Ion-Ion Energy

The nuclei (or ions, after core electrons are pseudized) interact via Coulomb
repulsion:

\[
E_{\mathrm{ion}} = \frac{1}{2} \sum_{i \neq j}
\frac{Z_i Z_j}{|\mathbf{r}_i - \mathbf{r}_j|}.
\]

This sum is **conditionally convergent** — it depends on the order of
summation. The **3D Ewald method** splits it into three absolutely convergent
pieces:

\[
E_{\mathrm{ewald}} =
E_{\mathrm{real}} + E_{\mathrm{recip}} + E_{\mathrm{self}},
\]

where:
- \f$E_{\mathrm{real}}\f$ sums short-range interactions in real space with
  complementary error functions,
- \f$E_{\mathrm{recip}}\f$ sums long-range interactions in reciprocal space,
- \f$E_{\mathrm{self}}\f$ removes the spurious self-interaction.

Atomiverse implements this in
[`include/atomiverse/cpu/pw/internal/ewald.h`](../../include/atomiverse/cpu/pw/internal/ewald.h).

## The Full Energy

The total energy per unit cell is

\[
E_{\mathrm{total}} =
\sum_{n}^{\mathrm{occ}} f_n \varepsilon_n
\;-\; E_{\mathrm{H}}[\rho]
\;-\; \int V_{\mathrm{xc}}(\mathbf{r})\rho(\mathbf{r})\,d\mathbf{r}
\;+\; E_{\mathrm{xc}}[\rho]
\;+\; E_{\mathrm{ewald}}.
\]

The first term is the band-structure energy (sum of occupied eigenvalues).
The next three terms correct for double-counting in the effective potential.
The final term is the Ewald ion-ion energy.

## What the Code Actually Does

The entry point is `pw::solve_si()` declared in
[`include/atomiverse/cpu/pw/solve_si.h`](../../include/atomiverse/cpu/pw/solve_si.h):

```cpp
namespace ATV::cpu::pw {
double solve_si(const std::string& upf_path = "",
                double ecut_ry = 30.0,
                int k_mesh = 4,
                double tol = 1e-6,
                int max_iter = 50);
}
```

The internal flow is:

```
cpu::Frame (Si diamond, 2 atoms)
  → GVectorList (30 Ry cutoff)
  → KPointGrid (4×4×4 MP mesh)
  → EwaldSummation (Z=4, a=5.43 Å)
  → PWWorkspace (shared density/potential arrays)
  → SCF loop:
      PW_Poisson  → V_H(G)
      PW_LDA      → V_xc(G) via FFT + evaluate_xc
      PW_Hamiltonian → T(G) diagonal
      PW_Veff     → V_eff = V_loc + V_H + V_xc
      PW_Davidson → lowest N_occ eigenpairs
      PW_Density  → ρ(G) + Pulay mixing
      PW_Convergence → check ||Δρ|| < tol
  → E_total = band energy + Ewald (Ry)
```

When no UPF file is provided, a **toy local potential** is used
(\f$V_{\mathrm{loc}} \propto -1/G^2\f$, a bare Coulomb tail). This toy
potential is useful for testing the software infrastructure but does not
produce physically meaningful energies. For production use, provide the path
to an SG15 ONCV UPF v1 file.

## FFTW3: The Computational Engine

The FFT operations that switch between \f$\rho(\mathbf{G})\f$ and
\f$\rho(\mathbf{r})\f$ are handled by **FFTW3** (Fastest Fourier Transform
in the West). Atomiverse wraps FFTW3 plans in a RAII `FFTPlan3D` class
declared in
[`include/atomiverse/cpu/pw/internal/fft.h`](../../include/atomiverse/cpu/pw/internal/fft.h).

The FFT grid dimensions are determined automatically from the G-vector list:
the grid must be at least \f$2 \times (\max n_i) + 1\f$ in each direction to
avoid wrap-around aliasing. For silicon at 30 Ry, this typically gives a grid
of \f$24\times24\times24\f$ or similar.

## Building with PW Support

The plane-wave module is gated behind the CMake option `ATV_BUILD_PW`:

```bash
cmake -B build -DATV_BUILD_PW=ON -DATV_BUILD_TESTS=ON
cmake --build build -j$(nproc)
ctest --test-dir build -R pw
```

This requires FFTW3 to be installed on your system. On macOS:

```bash
brew install fftw
```

On Ubuntu:

```bash
sudo apt install libfftw3-dev
```

## Running the Si Calculation

The C++ example:

```cpp
#include "atomiverse/cpu/pw/solve_si.h"
#include <iostream>

int main() {
    // Toy local potential (no UPF file)
    double e_toy = ATV::cpu::pw::solve_si();
    std::cout << "E_total (toy V_loc) = " << e_toy << " Ry" << std::endl;

    // With SG15 pseudopotential
    double e_sg15 = ATV::cpu::pw::solve_si("Si.upf", 30.0, 4, 1e-6, 50);
    std::cout << "E_total (SG15) = " << e_sg15 << " Ry" << std::endl;
    // Expected: ≈ -107.8 Ry
}
```

The Python equivalent:

```python
import atomiverse as av

result = av.solve_si(ecut_ry=30.0, k_mesh=4, tol=1e-6, max_iter=50)
print(f"E_total = {result.energy:.6f} Ry")
```

## Data Flow through Components

All six PW components share data through a `PWWorkspace` struct rather than
through the `cpu::Frame`. The workspace is attached to the `BuildContext` as a
`void*` pointer and cast by each component:

```
PWWorkspace
  ├── gvec → GVectorList (shared, read-only)
  ├── rho_G, rho_G_old (density, in/out)
  ├── V_H_G, V_xc_G, V_eff_G (potentials, intermediate)
  ├── V_loc_G_real (local PP, read-only, set by solve_si)
  ├── rho_r, V_xc_r (real-space work arrays)
  ├── T_G (kinetic diagonal, precomputed)
  ├── eigenvalues, eigenvectors (Davidson output)
  ├── mix_beta (mixing parameter)
  ├── mix_history (Pulay history buffers)
  └── converged, total_energy (output flags)
```

This design keeps components decoupled: each component reads and writes only
the workspace fields it needs, and no component depends on the internal
details of another.

## Convergence Behavior

The SCF convergence for silicon follows a typical pattern:

1. **Warmup** (iterations 1–2): The density changes substantially as the
   initial uniform guess relaxes. Convergence is not checked during this
   period.
2. **Rapid descent** (iterations 3–8): The residual drops by 1–2 orders of
   magnitude per iteration as the dominant Fourier components settle.
3. **Asymptotic tail** (iterations 9+): The residual decreases slowly. Pulay
   mixing helps here by extrapolating from the history.

For silicon at 30 Ry, typical convergence to \f$10^{-6}\f$ requires 10–15
iterations with linear mixing (\f$\beta=0.4\f$), or 8–10 with Pulay mixing.

## What Is Not Yet Implemented

The current v1 implementation is a working prototype. Several features are
simplified:

| Feature | Current state | Target |
|---------|--------------|--------|
| Davidson solver | Diagonal sorting only | Full iterative subspace |
| Non-local PP | Not applied | Kleinman-Bylander projectors in \f$\beta\f$-space |
| k-point parallelism | Serial over k-points | Band-group parallelization |
| Stress tensor | Not computed | Analytic stress from FFT derivatives |
| Atomic forces | Not computed | Hellmann-Feynman + Pulay corrections |
| Symmetry reduction | Not used | Irreducible k-point wedge |

These simplifications mean the code runs correctly but the band-structure
energies are not yet physically accurate with a real pseudopotential.
