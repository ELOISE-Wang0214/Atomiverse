# Spec: `voronoi-volume-tf` — Voronoi / site-volume companion for Thomas–Fermi metallicity

**Queue row:** map §1 "Voronoi volume (TF)" ○ — the TF `l_tf` foothold
(`ConstPotBO::l_tf` + `site_density`, wave 2 `thomas-fermi-electrode`) is done,
but the site-volume companion is absent: no way to obtain per-site Voronoi
volumes \(v_i\) from geometry, and no per-site volume path into the TF
hardness.

## Physics

Scalfi, Dufils, Reeves, Rotenberg, Salanne, *J. Chem. Phys.* **153**, 174704
(2020), DOI 10.1063/5.0028232: semiclassical Thomas–Fermi electrode
metallicity adds a quadratic self-energy per electrode atom

\[ U_{\mathrm{TF}} = \sum_i \frac{l_{\mathrm{TF}}^2}{2\,\epsilon_0\,v_i}\,q_i^2
   \;\Rightarrow\; A_{ii} \mathrel{+}= \frac{l_{\mathrm{TF}}^2}{\epsilon_0 v_i}
   = 4\pi k_e\,\frac{l_{\mathrm{TF}}^2}{v_i}, \]

where \(v_i\) is the **Voronoi volume of the atomic site** in the electrode
crystal. MetalWalls exposes this as the per-species electrode input
`voronoi_volume` next to `thomas_fermi_length` (gitlab `ampere2/metalwalls`,
branch `release`); for FCC gold \(v = a_0^3/4\) exactly. The wave-2 ATV
foothold hard-codes one global density \(d = 1/v\) (`site_density`); the MW
workflow supplies volumes.

## Deliverables

1. **`cpu::VoronoiVolume`** (`include/atomiverse/cpu/observe/voronoi_volume.h`
   + `src/cpu/observe/voronoi_volume.cpp`) — OOP geometry primitive, `ATV::cpu`
   namespace, no factory, no Config bag:
   - `std::vector<double> volumes(const cpu::Frame& frame) const` — periodic
     Voronoi cell volume [Å³] per frame row, tessellation generated by **all**
     atoms in the frame. Orthorhombic boxes only (throws on triclinic);
     throws on empty frame and on coincident sites.
   - Algorithm: per-atom convex-cell bisector clipping. Initial cell = the
     box cuboid centred on the atom (exactly the self-image bisectors for an
     orthorhombic lattice); clip by perpendicular-bisector half-spaces of all
     neighbor images within the initial-cell circumradius bound, nearest
     first, with early termination once the plane distance exceeds the
     current cell circumradius. Volume by per-face pyramid decomposition
     about the (interior) site. Setup-time companion — not a hot-path
     Component; no allocation constraints.
2. **`ConstPotBO` per-site TF volume path** (reuse, never duplicate):
   - New public member `std::vector<double> site_volume;` — per-site volume
     \(v_i\) [Å³] **indexed by frame row** (size = frame `nlocal`).
     Non-electrode rows ignored.
   - TF hardness becomes \(A_{ii} \mathrel{+}= 4\pi k_e l_{\mathrm{TF}}^2 /
     v_i\) when `site_volume` is non-empty; the fixed-density foothold
     \(A_{ii} \mathrel{+}= 4\pi k_e l_{\mathrm{TF}}^2 d\) is unchanged when
     `site_volume` is empty.
   - Validation (throw, no fallback): when `l_tf > 0`, **exactly one** of
     `site_density > 0` / non-empty `site_volume` must be set; when
     `site_volume` is used, its size must equal the frame `nlocal` and every
     electrode row must have \(v_i > 0\).
3. **Unit tests** (`tests/`, mirror source, seconds):
   - `tests/cpu/observe/test_voronoi_volume.cpp`: single atom = box volume;
     3-site unequal 1D split (exact widths); FCC conventional cell → each
     \(v_i = a_0^3/4\); perturbed lattice → \(\sum v_i = V_{\mathrm{box}}\);
     throws (empty frame, triclinic box, coincident sites).
   - `tests/cpu/dynamics/test_const_pot_site_volume.cpp`: uniform
     `site_volume` \(= 1/d\) reproduces the `site_density` twin charges to
     1e-12; halved volumes strictly reduce capacitance; validation throws
     (both set / neither / wrong size / non-positive electrode volume).
4. **Regression** `regressions/md/voronoi-volume-tf/` (out-of-library public
   API consumer, ≤ 60 s, targets `reg_voronoi-volume-tf` +
   `run_reg_voronoi-volume-tf`):
   - Bulk FCC Au 2×2×2 conventional cells (32 atoms, \(a_0 = 4.07\) Å):
     every computed \(v_i = a_0^3/4 = 16.85478575\) Å³ (≤ 1e-9 rel) and
     \(\sum v_i = 8 a_0^3\) (≤ 1e-10 rel).
   - TF gold capacitor toy (same geometry as wave-2 `thomas-fermi-electrode`):
     `ConstPotBO` with `l_tf = 2` Å and `site_volume` filled from the
     computed bulk \(v\) reproduces the MetalWalls-model pins
     (\(Q_{\mathrm{top}}\), \(C\)) ≤ 1 % and equals the in-binary
     fixed-density twin ≤ 1e-10 rel; neutrality ≤ 1e-10 e.
   - Metallicity gate: `site_volume` halved (denser sites → harder diagonal)
     strictly reduces \(C\); pinned \(Q_{\mathrm{top}}(v/2)\) ≤ 1 %.
   - `REFERENCE.md` with `oracle: metalwalls`, `oracle_version`, cited
     numbers, units, perf block.
5. **Offline pin** (`tools/metalwalls_oracle/`):
   - `inputs/metalwalls/voronoi-volume-tf/pin_voronoi_tf.py` — discrete
     BO+TF algebra with per-site volumes (extends the wave-2
     `pin_gold_cap.py` model); run offline, numbers hard-coded in the
     regression. ctest never launches an oracle.
   - `pin_notes_voronoi-volume-tf.md`.
6. **Product page** `docs/tutorial/methods/voronoi-volume-tf.md`.

## Out of scope

- Runtime re-tessellation inside the MD loop (movable electrodes) — MW itself
  takes `voronoi_volume` as a static per-species input.
- Triclinic Voronoi cells (electrochemical cells in this loop are
  orthorhombic; the class throws honestly).
- Radical/weighted (Laguerre) tessellation, per-electrode-group scalar API,
  CUDA port.

## Acceptance criteria

1. `cpu::VoronoiVolume().volumes(frame)` returns exact volumes on the SC,
   1D-split, and FCC lattices (unit tests green) and satisfies the
   \(\sum v_i = V_{\mathrm{box}}\) invariant on a perturbed lattice.
2. `ConstPotBO` with uniform `site_volume` \(= 1/d\) is charge-identical
   (1e-12) to the `site_density` foothold; validation throws listed above.
3. `reg_voronoi-volume-tf` passes: FCC \(v_i\) pin, MW-model \(Q\)/\(C\) pins
   (≤ 1 %), fixed-density equivalence (≤ 1e-10), halved-volume metallicity
   gate, neutrality.
4. Dual gate green under the MD-only configure (HF/PW/GPW/CUDA/Torch OFF):
   scoped build + `ctest -R` unit tests + `run_reg_voronoi-volume-tf`.
5. No new public factory / Config bag; Frame stays sole I/O; Component
   architecture untouched (`ConstPotBO` stays a `pre_force` Component).
6. perf: `perf_exempt` expected (no MetalWalls binary on host; LAMMPS has no
   TF/Voronoi electrode twin) with reason recorded in REFERENCE.md.
